# 新设计分步实施与验收

2026-11-20。依据《宠物店全局设计总档》及其指定专项，先交付可点击界面预览，再在本地 develop 分步实施。正式服发布另行确认。下列现状来自本次源码核查；实现和验证结果在各步完成后补记。

## 修改范围

| 模块 | 当前差距 | 本轮处理 |
| --- | --- | --- |
| 新动物标签 | 固定五条，评级与标签混存，没有稳定标签ID | 保留六项评级结构；新动物按五档容量生成1～5条，首条必出、余槽80%；来源父35%／母35%／重抽30%，缺维回重抽 |
| 繁育评级 | A→S10%、S→S+6% | 改7%／3%，保留研究、跨档护栏及缺陷算法 |
| 复评 | 玩家指定维度，同时重抽名称和稀有度 | 系统等概率选已有标签，只变稀有度；可能降档，保留一张一次、单只三次 |
| 订单、来客、估值 | 按文字与固定五维读标签；来客硬锁稀有度 | 稳定ID匹配，实际标签估值；新来客不硬锁稀有度，旧已生成需求照旧；报价成交继续复验 |
| 名册 | 固定高整行跳详情，无折叠 | 名册专用互斥展开、独立详情入口；选亲本和整窝选择保持原行为；综合评分位置保留但不填未经确定的公式 |
| 个体档案 | 左窄右宽，右侧显示标签／稀有度，四段估价拆解 | V5左侧加宽，右侧前五项仅属性／等级，图内右上实际标签，缺陷单列；删除四段拆解，保留实际报价和真实档案 |
| 阶段显示 | “约”字静态时长，旧倒计时格式 | 权威终点实时显示天／小时分钟／分秒，归零与回前台刷新阶段及操作 |
| 字体 | 系统雅黑、苹方、宋体及模拟粗体 | 导入指定Noto简体字体和真实400／700字重，统一公共文字入口，再查专用组件 |
| 赛事 | 目标差距百分制、旧杯线、公开百分位五奖档和同分抽签 | 独立实现新计分、内部规则快照校验、私人杯线及公开不同分数档排序；费用、奖励和收藏身份未确定前不切换游戏赛事结算 |

已具备的开局兔对、教学投喂、成长时间、房间投喂、签到、种源预约、课题和技能树保留；本轮只处理核查出的差异，不再重做这些系统。

## 界面预览

入口：[新设计交互预览](../output/new-design-preview-20261120/index.html)。包括名册、V5档案、复评和赛事样稿，使用项目现有像素资源。样例只在预览内变化，不写游戏存档。预览不显示未确认的综合评分数值、公开报名费、奖金或高价值道具售价。

## 分步顺序

1. **预览与界面确认范围。** 完成四组页面及窄屏检查；沿用正式设计，不重新选择视觉风格。
2. **标签、复评与交易一体改造。** 兼容层先行，覆盖开店、签到、房间套餐、教学、普通货架、预约、繁育全部新动物入口。保留旧动物、旧货架和已经生成的待产结果。标签数量生成后固定。
3. **对应游戏界面与字体。** 接通只读展示字段、名册与档案、复评提示和回执；原有选种、交易、留种和返回流程继续可用。用独立本地存档验证。
4. **赛事规则与接入准备。** 先验证独立计分和分数档排名，再处理赛期规则版本及旧报名快照保护。标签首测不同时切换赛事或扩房经济；新公开赛费用和奖励未确定时，只做可验证规则与界面预览。
5. **分别验收并形成候选。** 标签经济观察与赛事观察分开；手机真机和真人长期经营另记，自动化不替代这些验收。

## 待定内容

- 名册综合评分公式是否采用六项标签容量分：不自行决定。
- 公开赛报名费、获奖档数、奖池、奖金和领取方式：不沿用旧免费或固定五奖档代替。
- 私人赛“三档九杯”与旧28主题84杯的收藏身份衔接：保留历史杯册，确定后再切换收藏目录。
- 选育与道具在本批之后已补充确认。旧待定条目由[选育道具与双优选标记](选育道具与双优选标记-确认补充-2026-11-20.md)和[本地接入与验收](选育与道具改动及验收-2026-11-20.md)接续记录。
- 营养餐实际价格和长期收益：记录首测结果后校准，不因界面修改擅自改价。
