# 比赛与全部金币交易细则 v2.0
本版根据用户授权补齐未决项，作为首版设计基线；新增数字与边界为设计者决策，不冒称用户逐项指定。仅设计，尚未实现或长期平衡验收。

## 1. 赛事身份、报名及结果
私人P01～P28、公开O01～O12稳定身份。兔猫狗共用主题、目标及奖杯目录，私人84杯、公开60杯，不乘物种、不跨年重建。公开兔/猫/狗分别排名，每账号每周仅提交一只，选择物种即选择该榜；不能报三榜多领现金或同杯多次。排名N按本榜人数计算。允许选择对自己有利的合法物种，不暗中跨榜加权。

私人每轮三选一、提交一只，收费基准兔20/猫100/狗120。公开免费。所有报名需该账号拥有、活着、成年或老年、未在繁育中；已繁育者可报。不再加健全度B或两项S+等绝对高属性门槛。幼体、已离店、已死亡不能新报名。

报名成功原子保存快照、占本轮机会并扣私人费用；预览免费。提交后不能撤回、换动物或退次数；不锁动物，随后可出售、配种、复评，比赛快照不变。失败整笔不扣，响应未知查原请求，不二次扣费。技术性整期作废由服务端记录作废原因、退原实付私人报名费，不补造过期报名，不发杯/奖；正常成绩低或动物售出死亡不退款。

私人20:00至次日18:00报名，次日20:00结果及对应奖杯/动物荣誉；公开周一20:00至周五18:00报名，周六20:00个人结果、实际杯与达标20，周日20:00排名现金补差。均北京时间，区间左闭右开、服务器受理时刻为准。具体轮转与epoch见《赛事配置说明》。界面显示独立比赛名、截止/结果时间及本轮已报名，不用日期作名字。

## 2. 匹配评分、五档与同分
每维目标差0/1/2/≥3档得100/70/30/0；高于目标同样扣分。标签稀有度和花色不直接加比赛分，品质在市场与遗传仍有价值。私人等权平均，实际分<68无杯，68～<82铜、82～<95银、≥95金，每次只得实际最高一档，不连发低杯。

公开按CSV六维权重归一，排序键依次为：
1. 主匹配分高；
2. 最低单维匹配分高；
3. 精确命中维数多；
4. 按本场权重从大到小的维度顺序逐维比较匹配分；权重相同按性格/品相/毛发/体态/体型/健全度顺序。
全程精确有理数，界面小数不参与比较。比较的是匹配，不是裸属性、付费、早报名或动物ID。赛前明示权重与比较顺序。

同一物种榜有效报名账号数N；边界floor(5%N)、floor(20%N)、floor(50%N)、floor(80%N)、N。五段由高至低为桂冠、金、银、铜、纪念。N=100人数5/15/30/30/20；N=1仅纪念；N=2为银/纪念；N=5为金1、银1、铜2、纪念1；N<20可能没有桂冠，空段不补位。N=0无杯。所有有效报名者进入实际档位，低于68也可获其实际杯，但无达标现金。

这是本次授权下明确采用的方案：结合用户后来“大多数坚持参赛能得杯、头部有炫耀点”的方向，将旧100人总获杯不超过5改为最高桂冠不超过5，普通档可更多。不能对外误称用户旧句本来只指最高档。此限制按物种榜而非三榜合计。

上述比较键完全相同为真正并列。为保持各档人数边界，杯档跨界时采用可复算公平抽签：该期开放前服务端生成种子并公布SHA256承诺；截止时冻结报名清单；周六揭示种子，按HMAC-SHA256(seed,event_id|account_id)从小到大排列该并列组；极端哈希碰撞以另一预定义域名再次HMAC。每账号仅一次机会，不因改动物获得新签。不可重选种子、按付费或历史战绩操纵。抽签只决定同等成绩实际落在哪档，不改分数和并列现金。客户端可复算，本地榜须标模拟抽签。

每个周赛期称该期赛季结果，不新增另一套赛季重置/积分。周六展示五档昵称、账号公开短标识、动物历史、主分及细分，周日补现金结算状态。真实账户只显示其已用于游戏展示的昵称与公开ID，不公开联系信息。新主题不同要求给领先者变化机会，不保证强制换冠军。允许合法压分收藏低杯。

## 3. 奖杯、低档奖励与动物历史
每次只收实际档杯。每个赛事ID+档位唯一杯，三物种共杯；重复获同杯只累计次数。首获按结果计划时刻、事件ID稳定排序固定，不因离线打开顺序改变；首次动物快照永久保留，之后不替换。当前动物售出删除可操作档案，奖杯、报名、交易审计最小快照独立存在。先卖后获杯照常发给原报名账号。

“高档解锁低档奖励”落实为低档收益资格已被高档包容：玩家奖励详情显示下档资格已满足；只实际发该档的最高综合权益，不把收益百分比或多份档位现金相加。高档不能让低杯图标变已收集，低杯首获动物保持空，须以后实际获低档。公开现金只有本节下一部分的20保底及排名补差，私人无新增现金。这是本次对未定“奖励形式”的明确收口，不恢复旧40/90/180现金奖。

荣誉记录、奖杯记录与店铺评分分开：同动物真实获更高荣誉可更新自身价值；账号已有该杯的新动物也可获自身荣誉，但不再增加重复店铺评分。后代不继承荣誉。赛前不承诺获奖的未来价值。

## 4. 公开现金：20保底与排名补差
主分≥68者构成现金资格榜Nq，保持第2节比较键排序；杯档榜用全部有效N，两者人数明确区分。周六每位现金合格者先发G=20；不合格G=0。

现金位置基准：第1名540；2至min(Nq,max(3,ceil(.10Nq)))各270；随后至min(Nq,max(10,ceil(.30Nq)))各120；其余0。
Nq=0无款；Nq=1排名总奖R=0但达标20保留；2～9缩放k=(Nq−1)/9；≥10 k=1。
真正并列m人占连续位置时，每人 R=floor(k×占位基准奖金总和/m)，只在最终取整，不先每位置取整。下一名跳过占位数；抽签杯档不改变这笔并列现金。周日只发D=max(0,R−20)，合格者最终T=max(20,R)，不追回20。
100人全达标无并列：周六2000，周日4770，总6770；2人总90、5人总586、10人总1920。100人两人并列第一R405各补385，三人并列第一R360各补340。
周六未成功发保底时周日须先对账补齐G，再结差额；累计不可超过应发T。分阶段独立唯一流水防重，不把一次终生现金奖限制加回来。

赛事现金不是交易收入，不乘店铺评分。签到赠宠不乘、不套金币采购折扣；支付演示不产生任何资产，无收益或折扣计算。人民币支付尚未接入，不能借评分买金币放大。

## 5. 店铺评分及全交易价格
评分r为累计收益基点，100基点=1个百分点：
|模式|档位从低到高|各档贡献基点|
|---|---|---|
|私人|铜/银/金|20/60/100|
|公开|纪念/铜/银/金/桂冠|50/100/200/400/600|
每个赛事只取历史最高档贡献，相加得到r，当前40赛事最多28×100+12×600=10000，即R=r/10000最高1。重复同杯不加，升档替换，跨年不减、不重复叠年。不同赛事可加，公开同档贡献更高。该100%是首版40赛事集的设计上限，新增主题前重新做预算，不无限套入。满集意味着交易销售额2倍，不是承诺钱包、净利润或每位玩家三年2倍。

G=1+R，为全部金币出售类交易乘数。D=.05R，为所有金币购买类折扣，最大5%，防止采购过便宜再卖刷钱。
- 买入/支出：幼体采购、研究所升级、房间解锁、服务单、额外取消次数、装饰、私人报名费均乘(1−D)，最终整十向上取整。免费项目仍0，不凭空最低10。已确认价格作为R=0基准保留。
- 市场、普通订单、特殊来客和研究所的已故动物回收都乘G，每只四舍五入到个位（.5向上），批量逐只再相加。金额分阶段用精确小数／有理数，展示报价即最终金币。
- 四个入口共用多选规则，只结算玩家明确勾选的个体。市场收空闲活体，研究所只收空闲的已故个体，普通单与来客只收符合各自条件的空闲活体。所有渠道均排除标记为「种源」的动物，整窝出售同样适用。从档案进入可预选该只符合条件的动物。零选不能提交。确认页列出逐只报价与总额。如果卖出后房间将失去最后一只未繁育的公本或母本，则按整批余量提醒玩家。
- 提交时在同一事务内复核每个唯一动物 ID、资格、报价以及订单或来客状态。任何一项失效或变价，告知涉及的个体并刷新，等玩家再次确认；原批次不扣动物、不入账。成功后一次移出全部所选个体，金币流水记分项和合计，重复请求返回原收据。一批只完成当前订单槽一次或让当前来客离开一次，同一只动物不可同时卖给别的买家。
- 原有按次交付一只的经济试算未覆盖囤积多只后按同一订单或来客倍率成批出售的收入。渠道倍率沿用第6节的公式，批量行为的长期收益需单独验证。
- 新评分只影响之后成交；重试读取原成交金额，不重新套评分。交易前变价重新报价并确认。不同动物不能人为切成多笔相同动物套利。
- 小额购买因整十可能不实际降价，显示基准/实付，不虚报省钱。例如满R台灯60×.95=57→60、猫复评300→290。
- 每阶段比赛资格与固定现金不套D/G。服务是金币购买故套D；装饰本身无收益，折扣不让装饰产生属性。

## 6. 动物价值、荣誉及回收
halfup(x)=floor(x+.5)，ceil10(x)=10ceil(x/10)。
B=C×K；C兔100、猫1200、狗1300；K按主文四档。T幼/成长/成年/老年=.8/.92/1/.65。Q=1+.05×(六维索引均值−3)+.03×少见数+.08×稀有数；五栏同栏只计一种，Q范围.85～1.55。
V=halfup(B×T×Q)，Va=halfup(B×Q)。时间价值已在C，不再乘成长时间比。性别/花色无额外价。
未繁育Vb=V；设对应物种繁育后价值研究等级Lv∈0～10，s=.20+.005Lv；已繁育Vb=max(max(1,floor(.06B)),halfup(s×V))，保留20%～25%且不低于既有基础尸体回收。不新增另一层保底或重复乘研究系数，Lv在成交核价时读取；变价重新报价。

动物荣誉系数h取其真实获奖最高：私人铜0/银.4/金.8；公开纪念0/铜.2/银.4/金.6/桂冠.8。H=floor(B×h)，不随重复/多赛累加，不传后代。只有该动物自己的实际结果产生H；不能因账号已有金杯让新购动物继承荣誉。

|渠道|统一计算|
|---|---|
|研究所幼体采购|先P0=ceil10(2.8×V幼)，实付ceil10(P0×(1−D))；新品H=0|
|市场|halfup(G×(Vb+H))|
|常规/标准/定向单|halfup(G×(1.35/1.55/1.80×Vb+H))|
|特殊来客|halfup(G×(2.15×Vb+H))|
|死亡研究回收|先F=max(1,floor(.06B))；H>0时F=max(F,floor(.1Va+.5H))；到账halfup(G×F)|

订单和来客的渠道倍率仅用于基础价值。动物自然死亡后只可回收一次，死亡回收独立计价，不套已繁育20%～25%售价系数。

结果时还在店（含未回收尸体）才更新动物H及未来报价；先卖出/已回收则只给原账号奖杯、记录与应得现金，不追补旧交易价、不恢复资产。此“不追补”由本次授权正式采用，不再只是旧模拟假设。已售历史可展示后来比赛荣誉但不得触发经济操作。给奖时间按事件计划时刻推进后才允许同刻交易，避免结算顺序随登录变化。

以下数例为价值研究0级。满评分全B英短：P0=2690→2560；成年市场2400，直接买长大卖仍亏160；1.35单3240、1.8单4320、来客5160，属需成熟、匹配和刷新机会的经营盈利。该猫获得h=.8则H=960，市场4320、来客7080，不是9288。已繁育后Vb240，h=.8市场2400，死亡后由研究所按F600回收，到账1200。

## 7. 验证与实施界限
独立经济审查按最终逐只halfup复算9324理论组合×4个评分档，普通无荣誉幼体→成年市场路径0条正收益；R=0/.25/.5/1最优净差为−111/−89/−66/−12金币。另枚举372960种物种/品种/评分/标签/荣誉/阶段/繁育状态组合，死亡回收≤活体研究回收≤普通市场，0条违规。这是静态公式验证，不是全路径或长期平衡证明。订单、来客、荣誉形成的正收益不自动叫漏洞，它们受养成、主题、报名等待和成交次数限制，仍需长期压力测试。
五档小人数与同分、20保底、全部交易变价、同场覆盖、荣誉与店铺两种对象、离店历史分离按验收逐项执行。新40模板、分物种榜与评分交易规则已进行三年启发策略模拟，见[v2长期养成与交易风险试算](v2长期养成与交易风险试算记录-2026-11-14.md)；该范围联合达成尚未达到半数，不是现实玩家预测。普通市场路径静态无正差不排除购幼体立即交匹配订单的有界盈利；提高采购底价候选未采用，以上公式不变。
房间套餐现行基准：猫3000含英短幼体公母、狗20000含柴犬幼体公母，具体属性见主表。套餐总价按ceil10(P×(1−.05R))一次扣款，满评分分别2850/19000，不再另扣所含动物采购费。普通研究所单独采购公式不变。
