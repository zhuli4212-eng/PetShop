## 2. 已确认加入：定向种源预约

**方向**：增加可选择使用的定向种源预约，减少为了取得合适种源而反复盯货架的负担，为经营规划提供消费选择。不是强制配种费，也不是开房首对的第二笔费用。

### 此前候选，不是定价结论
- 猫预约服务费200金币、狗500金币，种源购价另按正常规则结算。
- 按品种与性别定向，为下次上线保留普通种源；每物种每日1份曾作为讨论候选。
- 保留已出现的库存，还是预约未来符合条件的库存，尚未决定，不能将二者混为同一实现。
- 不以保证稀有标签或高等级作为已确认权益。

### 必须补齐后才能实施
预约开放条件；可预约物种和筛选项；每次/每天/同时持有上限；保留时间（包括曾讨论的24小时）；是否影响普通30分钟货架；预约费何时扣、购价何时锁定；取消、到期、缺货及退款；动物年龄从何时起算；离线领取和跨日状态；是否允许与普通采购、首次引导货架重复占用。

设计底线：普通货架与基本补种渠道不应因新增预约而被替代或强制收费；预约价值与成本需要独立验证。开动物房包含首对公母幼体、只付一次套餐价的既有约定保持。

## 3. 已确认加入：品种培育课题

**方向**：增加围绕品种培育的中长期目标，让玩家有理由投入金币与培育成果，承接短期任务之外的长期追求。加入方向已确认，具体内容未定。

### 此前候选，不是正式成本或奖励表
- 猫课题三档3000 / 6000 / 12000金币；狗课题三档8000 / 16000 / 32000金币。
- 结合指定品种、标签或组合成果完成；是否需要提交并消耗动物、仅验证拥有、或记录曾培育成功，尚未确认。
- 图鉴、命名、展示权益曾作为奖励候选；不得写成已经获批的具体资产、皮肤或收益加成。
- 自愿选择、不作为基础繁育或开房硬门槛，是此前方案定位；具体解锁阶段、任务链与玩家投入节奏仍待细化。

### 必须补齐后才能实施
课题清单与分级；开放门槛和前置；验收所需品种、性别、标签、维度及数量；动物占用/消耗规则；金币扣款时点；是否允许撤回及退款；奖励清单和是否影响经济；可重复性；存量成果是否追认；周期性与长期目标的关系。

不因本次确认而加入强制维护费、每日缴费或强制每窝收费。奖励如果增加收入或繁育效率，必须连同成本重新验证，不能视为纯金币回收。

## 4. 既有已确认新设计一并归档

- 正式名称使用“动物小屋”“培育中心”。
- 首小时体验目标是持续有事可做；由用户负责具体引导步骤、美术和界面规划，不在本记录重做这些内容。
- 保留用户0–17引导顺序：登录 → 背景预留 → 动物小屋解锁兔房 → 投饲料 → 主界面繁育台 → 首窝特殊5秒 → 查看首窝 → 第一只动物六维 → 主界面自由市场 → 卖一个已繁育亲本 → 另一未售亲本去世 → 培育中心 → 回收并提醒只能此处回收 → 买两只成年种源 → 动物小屋繁育新种源并说明成长阶段 → 主界面领取已完成任务 → 三订单中选第一单完成 → 主界面结束、自主经营。详细触发、文案、防卡以正式引导文档为准。
- 喂养以整间动物小屋为范围，成长速度2倍；首对在引导首次喂养后立即成年，明确提示一次性新手特例，不推广到普通动物。
- 首窝5秒仅是新手特殊处理；未确认首窝固定4只或固定性别。
- 去世演示处不加额外提醒；具体死亡处理方式仍待定，不能擅自强制杀死普通动物或快进全局时间。
- 新开局使用原色幼兔一公一母；首日签到安哥拉、后续不同品种循环为新方向，具体循环表尚未定。培育中心首次成年垂耳种源与普通货架区分。
- 经营阶段目标：兔为第1–3天主力，猫承接第4–15天，狗在第15天后成为主力。这是体验目标，不是已通过模拟的结论，也不是未经确认的按日期硬锁。
- 猫狗后续养成应有更丰富、更有价值的消费，而不只是降低售价或抬高一次性开房门槛；保留不喂养和低频回归的经营选择。
