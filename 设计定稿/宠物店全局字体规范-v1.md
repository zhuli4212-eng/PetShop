# 宠物店｜全局字体与文字排版规范 v1.0

**适用范围：**玩家端所有现有界面、新增界面、弹窗、列表卡片、浮层和系统反馈。本文给的是设计与开发的目标值，不是已上线的样式清单。现有场景、美术、游戏规则和文案业务含义不在本次修改范围。

> **正式设计依据（2026-11-20）**：本规范与[全局设计总档](宠物店全局设计总档-2026-11-20.md)、[V5 展示设计](动物名册与个体档案-V5展示设计定稿-2026-11-20.md)配套生效，旧稿和预览的冲突样式以新设计为准。示意图右上角按[五档标签专项](五档动物标签与特征复评-首测定稿-2026-11-20.md)展示实际特征标签，使用 T17；旧品质称号占位 T30 退役。设计确认不表示字体已导入、代码已修改或发布完成。

## 1. 字体资产与尺寸基准

| 用途 | 唯一设计字体 | 使用字重 |
|---|---|---|
| 页面标题、章标题、主卡标题和档案动物姓名 | **Noto Serif CJK SC**（简体中文） | Bold 700 |
| 正文、导航、表格、按钮、属性评级、金额、倒计时、输入 | **Noto Sans CJK SC**（简体中文） | Regular 400、Bold 700 |

- 字号与行高依据当前 Cocos **390×844 逻辑设计分辨率（固定宽适配）**，390 宽设计下可直接填项目单位，不是手机物理像素。780 宽导出的标注图是 2 倍物理稿，不把标注值再乘 2。只有根布局负责适配缩放。
- Cocos 把三份实际字体资源（宋体风格 Bold、无衬线 Regular/Bold）导入为字体资产，常规 Label 禁用系统字体、绑定正确字重的资产。不要用 Regular 加描边或模拟粗体。Web 预览如需保真，也要随包加载对应的简体字体。数字与字母不得另掉到系统默认字族。
- 项目原实现依赖微软雅黑、苹方、宋体等系统候选，同名界面在不同设备可能长得不同。**系统候选不是交付字体**。本规范选择可固定打包的 Noto CJK 作为目标；发布前要锁定实际字体文件和版本，随包保留许可，验证缺字、动态昵称和资源体积。品牌字标、烘焙进美术的文字、操作系统原生提示不强制换字族，但新增游戏信息不烘焙到图片。
- 当前通用正文是 `#443A29`，次要字是 `#6C5E46`，商业界面另有 `#493B28`／`#705B3D` 等；这些是**现状**，下面表中的颜色是**设计目标**。不更换现有背景和美术，迁移时逐组件核对实际底色，避免贸然用一套色值覆盖所有深浅背景。
- 来源：[Noto CJK 官方字体说明](https://github.com/notofonts/noto-cjk/blob/main/README.md)；字体许可：[Sans](https://github.com/notofonts/noto-cjk/blob/main/Sans/README-third_party.md)、[Serif](https://github.com/notofonts/noto-cjk/blob/main/Serif/README-third_party.md)。

## 3. 全角、半角和数字格式

| 场景 | 标准 | 正确示例 |
|---|---|---|
| 中文句子、括注 | 中文逗号、句号、冒号、问号、括号用全角；标点两侧不塞空格。独立字段名不补冒号 | `请核对亲本，确认后开始繁育。`　`2026-11-19 01:53:23（北京）` |
| 数字、英文字母、代码与评级符号 | 半角 ASCII；不转全角，不拆 `S+`；程序编号前的 `#` 半角且紧贴 | `S+`　`#31953`，不用 `Ｓ＋` 或 `＃31953` |
| 金币、数量、分数 | 半角数字，≥1,000 用半角逗号分组；数值与单位间 1 个半角空格；编号、日期不做千分位 | `6,000 金币`　`3 只`　`96 分` |
| 百分比、小数、倍率 | 半角 `%`、小数点和符号，贴数值；营养餐倍数用「倍」而非字母 x | `+10%`　`35%`　`1.8 倍` |
| 次数／进度、亲本、日期 | 次数分隔 `/` 半角，两边各 1 个半角空格；亲本分隔可同用；日期时间半角连字符和冒号 | `复评 0 / 3 次`　`母 谷穗 / 父 小麦`　`2026-11-19 02:23:23` |
| 卡片元信息 | 分隔用 ` · `（中点 U+00B7，两侧各一个半角空格）；不以全角空格对齐 | `安哥拉兔 · 雪白`　`完美无缺 · S+` |
| 时间倒计时 | 数字半角，数字与中文单位间各留 1 个半角空格，不写「约」、不补前导零；用布局防断开而非把文本改成连续空格 | `1 天`　`2 小时 14 分`　`58 分 9 秒` |
| 用户输入 | 保留昵称原字形与标点，不静默改半角或大小写；搜索匹配可用归一化，不回写显示值 | 玩家自定昵称原样呈现 |

**阶段倒计时规则。** 用阶段终点减当前时间，而不是点击后靠秒计数累加。剩余 ≥24 小时只显示完整天数；≥1 小时且 <24 小时显示小时、分钟；<1 小时显示分钟、秒。刚好 24 小时为「1 天」，刚好 1 小时为「1 小时 0 分」。1 小时前最后一档不出现「60 分」，归零不为负；游戏按实际阶段状态更新，不新增死亡提示。不影响实际年龄、出生及成年时刻的显示。临界秒和切到后台再返回都要测试。

**对齐。** 金额、排行、分数和动态时间统一对齐数列。字体渲染器支持时用 tabular figures；不支持时用固定宽数字槽，不得换用另一字体。字段和值用栅格，不用空格凑位置。正文可换行，等级、编号、金额和单个时间单位组不拆行。

## 5. 实现验收

1. **字体不回落：**在 Cocos 检查 Label 的实际字体资产及对应字重，分别在 Windows 预览和目标手机验收。检查「芋头、臻选、绒光、S+、#、%」与英文数字宽度。浏览器预览只在确认资源加载成功后才用于比对字形。
2. **尺寸和色值：**按 390 与至少 320、430 两种相邻逻辑宽度确认，不挤出、标题不覆盖按钮、表格值可读。验收深绿上的浅金、营养餐进度信息、禁用项和三种标签的字色／底色组合；缺陷不套稀有度颜色。
3. **行为不串：**名册默认收起、只展开一张；独立「查看详情」。编号仅档案显示；档案沿用现有基础信息与入口，不恢复估值拆解四项。特征表只显示「属性／等级」两列，实际标签按 T17 放在动物示意图内部右上角，最多五条可分两行，不恢复 T30 占位；缺陷与种源各自独立。旧动物不按新容量裁标签，标签业务按五档专项执行，不由字体或排版改写。市场核价和留种流程继续按正式规则验证。
4. **数字和标点：**检查 `6,000 金币`、`S+`、`#31953`、`复评 0 / 3 次`、日期及倒计时的逐字符显示；计时数字变化不推挤相邻内容，不将展现格式回写业务数据。
5. **动态状态：**长名字、缺字、空列表、禁用、成功／失败分别检查。大字态优先保证阅读与换行，不用逆向缩放挤进原框。倒计时 24 小时与 1 小时门槛、1 秒及归零按本规范检查。
