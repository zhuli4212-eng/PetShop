# 麦穗宠物店设计

**正式设计已确认（2026-11-20）。** 用户确认 Dot 中新落档的设计为正式设计，旧设计冲突处按新设计执行。[宠物店全局设计总档](宠物店全局设计总档-2026-11-20.md)及其指定的最新专项是正式依据；未冲突的旧细则继续有效。已选定的首测参数作为开发与首测基线，明确待定的价格、投放和奖励等不自动补值。

设计确认、代码实现、验收和部署分别记录。本次只更新设计文件，正式服版本按部署记录核对。
