# 选育与道具改动及验收

2026-11-20。依据 Dot 落档的本地副本[选育道具与双优选标记](选育道具与双优选标记-确认补充-2026-11-20.md)和本轮确认。用户明确指导单本地首测五项各 20%，所有道具默认开放。缺陷重塑限成年前，每只一生最多 3 次，越界时保留原档并消耗 1 份。

| 范围 | 本地改动 |
| --- | --- |
| 培育中心 → 物品 | 已开放物种房间默认列出复评、指导、单项、双项、缺陷重塑和抗衰老。保留已有培育中心开放条件和各房独立库存。五件高价值道具按专项的兔／猫／狗售价成交，复评沿用原核价。旧档缺少的新库存计为 0。单据按张、药剂按份。 |
| 选育指导单 | 繁育确认页进入「添加道具」。由服务端抽取五项之一，双亲同档也在池内。异档按高／低 80%／20% 作为遗传起点，再按原规则升降。同档照常遗传。整窝获得绿色「优选」。同一对亲本再次预览保持抽取结果一致。 |
| 单项与双项 | 玩家选 1／2 项不同普通属性，系统在开始繁育时选定同窝一只。该只所选项锁定双亲较高档，其余按适用规则生成。先确定评级再抽标签。可以和旧指导单同窝使用，选中幼崽获得蓝色「优选」。 |
| 档案和出生 | 绿色、蓝色「优选」在档案动物图内的种源位置下方并列，和真实标签各自显示。待产结果在开始繁育时保存，已有待产窝按已保存结果出生。 |
| 缺陷重塑 | 尚未成年且在店的动物可用。55% 升一档，45% 降一档，越界不改变档位但照常扣库存和次数。每只一生最多 3 次，可用于有选育标记的动物。仅改缺陷及该道具使用次数。 |
| 抗衰老 | 在店活体可用，每份只延长老年期 1 天，一生最多 3 次，成年与进入老年时间保持原计算。档案显示已用次数和延长天数。 |
| 提交与回执 | 浏览、选择及取消时不扣单。开始繁育才扣所选单据，药剂确认后扣 1 份。价格、资格和库存由服务端检查；交易沿用现有版本校验和回执。 |

待定设定：双亲同档的额外增益，本版沿用自然遗传；两种新选育单彼此能否同窝叠用，本版每窝最多添加其中一种。口语化全文仍为文案评审稿，游戏中的购买与使用提示按上表规则撰写。
