# 界面层级与返回逻辑

2026-11-16 确认。适用于正式游戏和本地界面预览。

## 一、三个层级

| 层级 | 玩家所在的位置 | 顶栏返回的落点 |
| --- | --- | --- |
| 一级 · 店铺 | 店长所在的店内主场景 | 游戏内不显示返回按钮。 |
| 二级 · 功能界面 | 当前正在使用的一项完整功能，如动物房间、订单夹、繁育台 | 一次回到店铺。 |
| 三级 · 功能弹窗 | 当前功能里打开的一份档案、一笔交易或一次操作 | 一次关闭整个弹窗，回到打开它的二级功能，恢复当时的栏目与列表位置。 |

同一时刻只有一个二级功能、至多一个三级弹窗。三级内容较多时可以全屏显示，顶栏规则相同。二级左上显示「返回」，三级左上也可用「返回」，小弹窗可用「关闭」。游戏接收到 Esc 或宿主返回事件时，执行与当前可见返回按钮相同的动作。

## 二、各功能的归属

| 二级功能 | 留在二级内切换的内容 | 在本功能打开的三级内容 |
| --- | --- | --- |
| 动物房间 | 兔、猫、狗门牌，锁定房间的套餐和价格，名册状态、性别、滚动位置 | 个体档案与留种、本房挑选出售、解锁确认、本房最近一窝及留种售余 |
| 繁育台 | 当前物种、亲本双槽及候选名单、进行中或已完成的一窝 | 核对配对与开始确认、本窝个体档案、本窝留种售余 |
| 订单夹 | 三个订单槽、当前关注的委托 | 委托详情、交付清单与核价、取消委托确认、购买额外取消次数 |
| 来客簿 | 当前来客与收购条件 | 选择交付动物与核价、婉拒来客确认 |
| 自由市场 | 本店可售动物、已勾选的个体 | 核对批量报价并确认交付 |
| 研究所 | 幼体货架、研究手册、服务单、回收窗口及对应物种 | 幼体详情与购买、研究节点与升级、服务单购买与个体复评、回收报价 |
| 赛展台 | 当前赛事、参赛记录、历届榜单，以及赛期、物种和奖档选择 | 本场报名与核对、成绩详情、参赛者快照 |
| 奖杯收藏册 | 私人／公开册、所选主题与奖档 | 奖杯详情、首获动物与历史成绩 |
| 每日签到 | 今日领取状态、已领幼体 | 点所领幼体打开的个体档案 |
| 店内装饰 | 装饰目录、摆出与收起 | 购买装饰的确认窗 |
| 店主登记簿 | 本机经营档、服务连接状态 | 模拟支付演示，确认、处理与结果均在同一窗内 |

动物房间取当前筛选名册的前 10 只，进入时随机散布在地板上。切换同一房间的筛选时，仍在画面里的动物保留原来的落点；从档案返回也沿用本次布局。退出后重新进房会重新选点。状态与性别可组合筛选。「全部」包括仍在店的已故动物，「种源」按留种标记，「未繁育」按名册中的未繁育状态，「已故」按生命阶段。筛选无匹配时，房景和名册同时清空。

首页侧门与「进入兔房」共用动物房间。首页的奖杯入口与赛展台内的「奖杯收藏」共用奖杯收藏册。房间门牌、下拉筛选、研究分支选项、榜单分页和顶部提示均不增加层级。下拉框展开时，第一次返回只收起选项。

## 三、怎么判断下一次返回

1. **打开详情，记住发起功能。** 同一只兔子，从兔房打开档案就回兔房，从签到簿打开就回签到簿。关闭时恢复物种、筛选、页签、仍有效的勾选和滚动位置。名册发生变化时，优先定位原个体，已离店则落在相邻行。
2. **明确前往另一项功能，切换二级。** 例如猫房点「进繁育台」，打开猫繁育台，再点返回就到店铺。档案点「前往自由市场」，关闭档案并进入自由市场，可预选该动物。相反，猫房点「挑选出售」是在猫房就地办理，核价窗的归属仍是猫房。按钮文字应让玩家看得出这两种去向。
3. **同一件事的多个步骤，共用一个三级弹窗。** 订单交付或房内出售，在一个窗内完成选动物、核价和确认。点「修改选择」回到窗内已勾选的清单，点顶栏「返回」直接回所属二级。自由市场和研究所回收窗口的勾选清单已经在二级，关闭报价即可改选。查看研究前置、0–10 级效果和核对升级也用同一窗。确有重选或回看需要时，提供「修改亲本」「查看原节点」等具名动作。
4. **返回和提交分别处理。** 退出未提交的三级流程，丢弃本窗草稿，保留进入前的二级状态。例如市场列表原有的勾选仍在，订单弹窗内新勾选的动物随窗关闭。留种、解锁、配对、出售、婉拒等均由各自的明确操作触发。已提交的操作按服务器回执刷新，即使此时离开页面，结果也只处理一次。
5. **成功后的落点按业务决定。** 留种后留在当前档案，方便立即查看「种源」标签。售出或回收成功，关闭交易窗并刷新发起功能，清除已交付的勾选。开始繁育后在繁育台看进度。报名成功可在同一窗查看报名记录，关闭回赛展台。解锁成功留在刚开放的物种房。重新进二级时按所点入口打开，不重开旧弹窗。

## 四、用这些路径验收

| 操作路径 | 应看到的结果 |
| --- | --- |
| 店铺 → 兔房 → 选「未繁育＋母」并滚动 → 档案 → 留种 → 返回 | 仍在兔房原筛选和原位置，名册显示「种源」。再返回到店铺。 |
| 店铺 → 兔房 → 猫房 → 狗房 → 返回 | 一次到店铺。处于锁定房间时，返回不触发解锁。 |
| 猫房 → 进繁育台 → 选亲本 → 核对配对 | 「修改亲本」回猫繁育台并保留两槽。在确认前直接返回也回猫繁育台，繁育尚未开始。再返回到店铺。 |
| 订单夹 → 某张委托 → 勾选两只 → 核对报价 | 「修改选择」仍勾着两只。顶栏返回直接回订单夹，委托仍在。确认交付成功则回订单夹，显示该槽的新状态。 |
| 分别从猫房「挑选出售」、市场柜台、研究所回收窗口打开报价 | 关闭外观相同的报价窗，分别落在猫房、自由市场、研究所原物种的回收栏目。 |
| 研究手册 → 稀有标签节点 → 查看前置 → 查看等级效果 → 返回 | 一次回研究所手册，保留所选物种。再返回到店铺。 |
| 赛展台 → 奖杯收藏册 → 某主题首获记录 → 返回 | 回收藏册原主题，再返回到店铺。从赛展台自己的参赛记录打开成绩，关闭则回赛展台。 |
| 来客簿 → 交付清单 → 返回，随后离开来客簿 | 关闭窗口和离开功能均不婉拒来客，客人的有效状态按游戏时间更新。 |
