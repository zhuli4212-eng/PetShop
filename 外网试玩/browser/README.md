## 公开免登录试玩

游客打开页面后直接进入新手开局。试玩店铺保存在当前浏览器的 IndexedDB，换浏览器或清除本站数据会重新开店。试玩使用独立的 Pages 项目 `petshop-demo`。[公开试玩入口](https://petshop-demo-6ib.pages.dev/)

从工程根目录运行 `node 外网试玩/browser/build.mjs --demo --out <新的输出目录>`，默认使用 `PetShop/build/web-mobile` 的现有客户端。通过 `wrangler pages deploy <输出目录> --project-name petshop-demo --branch demo` 发布该静态目录。

2026-11-19 首次发布使用源提交 `2d5be68`，客户端版本为 `demo-5be4838841ec0a09`，Pages 部署 ID 为 `6d691fca-5f50-46cc-84ea-4cee8851ce86`。

本地通过 105 项游戏逻辑测试及 390 像素宽的触屏引导流程。公开入口通过游客开局、点击引导、刷新续玩及新浏览器独立开店检查。线上首页、Service Worker 和版本清单的 SHA-256 与发布目录一致。

## 账号试玩与历史发布

个人网站把本目录的 `dist/` 发布到 `/petshop/`，独立站把同一套文件发布到网站根目录。前端从当前站点的 `/petshop-api/v1/` 登录、注册和经营。两个 Pages 项目根目录使用同一份原生 API Worker 并绑定同一个试玩 D1，个人站的其它栏目保留当前发布快照。打包方法见[试玩账号服务](../accounts/README.md)。

打开或刷新时依次显示 Cocos 标题、开场动画和店主登录。登录页沿用店面铺底、表单靠下的布局。账号验证后加载店铺字体和音效，再进入游戏。市场、赛事等场景资源在打开相应页面时加载。新玩家点「注册账号」输入账号名，设置 8 至 128 个字符的密码。手机或电脑从任一正式入口输入账号和密码，都能续玩同一家店。页面只记住上次成功登录的账号名。

启动资源报错或 45 秒内未到达开场或登录时，页面提供「重新载入」。登录请求超过 12 秒可在原表单重试。注册和旧账号设密读取浏览器旧存档最多等待 5 秒。游戏页面收到数据后最多等插画 400 毫秒，之后先显示内容和操作。

旧免密码账号若仍在游戏里，先打开「账号」查看店主登记簿里的「设置密码验证码」，再在另一个标签页点「旧账号设置密码」。验证码 15 分钟有效。曾从本地浏览器导入这家店的玩家，也可在原浏览器用旧店凭据设置密码。完成后，两端改用新密码登录，原有动物和经营进度照常保留。两种凭据均已丢失的旧免密账号，其云端存档仍保留，但无法仅凭名字自助设密。

升级前的匿名 IndexedDB 店铺也可在原网址和浏览器点「注册账号」，勾选「将此浏览器的旧店复制到新账号」带入。重名注册会提示换名。

在正式项目构建好 `云端经营版/dist/client` 后，从本目录运行 `pnpm install --frozen-lockfile` 和 `node build.mjs`。用 `python -B check.py --local-api http://127.0.0.1:端口` 对临时数据库运行注册、续玩、旧档迁移和游戏流程验收。`python -B check.py --url <试玩地址>` 检查线上登录和注册表单。

账号网页使用 `--version` 打正式包时转换三份完整字体为 WOFF2。本地用 `--compress-fonts` 验证同样的格式。打包用的 Python 环境需安装 `fonttools==4.68.0` 和 `brotli==1.2.1`，可通过 `PETSHOP_FONT_PYTHON` 指定该环境的解释器。
