# 麦穗宠物店首页拼图

打开 [首页拼图预览.html](首页拼图预览.html) 即可离线查看。点「新版摆放」和「原版复原」切换对照。「摆放物件」支持拖动、输入坐标、调整图层顺序、隐藏和恢复。布局以 JSON 导出，下次可导入继续调整。

| 位置 | 本地预览中的改动 |
| --- | --- |
| 动物房间门 | 在原门牌上加入兔子和爪印 |
| 右上赛事柜 | 保留柜框，上层入口为「赛事」，下层为「荣誉」。罐子改为奖牌、奖杯和荣誉册 |
| 左侧培育中心 | 木柜上换成动物档案、饲料盒和喂养用具 |
| 窗户 | 装饰入口移到窗户，挂上绿色枝叶和纸饰 |
| 右侧繁育 | 藤篮换成带草垫的低矮木窝 |
| 左下任务簿、门口礼物 | 原台面改放任务册。门口礼物在模拟签到成功后消失 |
| 订单柜台 | 保留「普通订单」招牌，订单内加「特殊来客」。点「模拟新来客」可预览首页弹窗及前往订单的行为 |

## 素材

- [首页效果图.png](首页效果图.png) 是带招牌和店长的 409 像素宽预览。[原版复原.png](原版复原.png) 和 [新版摆放.png](新版摆放.png) 是 640 × 1120 的场景图。
- `图层/` 存放墙面地板、原版物件和新版透明 PNG。`scene-data.js` 存放叠放顺序、摆放坐标及点击区域。坐标原点在场景左上角，单位为原图像素。地毯、门垫和店长在预览里固定定位。
- 原始底图来自 `PetShop/assets/art/shop-interior.png`。原版拆分并重新叠放后的像素与原底图完全相同。新版在需要移除旧物件的范围内延续附近木纹，家具被遮挡的表面为补绘。变更范围外的底图像素保持一致。见 [像素校验.json](像素校验.json)。
- [物件参考-ImageGen.png](物件参考-ImageGen.png) 由内置 ImageGen 生成，局部提取为新版物件。完整 [出图提示词](出图提示词.txt) 随素材保存。
- 更改拆分形状或默认摆放时，使用 Node.js 和 FFmpeg 运行 `node build-layers.mjs`。从预览导出的布局文件可独立保存。

目前交互用本地演示状态，刷新页面即可恢复。签到、任务和来客尚待确认后接入本地游戏。
