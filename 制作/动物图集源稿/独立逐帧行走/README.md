# 动物行走动作

每只动物分别以本品种、毛色、性别和年龄的静帧作为外形参考。成年和幼年分别作画。兔的四个姿势需看清蓄力、蹬地、腾空收腿和前爪落地。猫狗要能看清近侧与远侧腿交替领步、抬爪与承重；同侧体表斑纹在四帧间应当连贯。

保留绘制原稿和提示词。导出时拆帧、清理透明边缘，四帧使用同一倍率，按身体和脚底接触点登记位置。正式动作条为 384×96 的透明 PNG，依次放四个 96×96 的帧。地面接触线为 y=89。兔子的腾空高度绘在动作帧中，房间只负责沿地面路径移动。

把完成的动作按实际资源键登记在[动作来源](动作来源.json)。在项目根目录运行 `python 制作/动物图集源稿/build_walk_sheets.py` 将登记的成品原样复制到游戏目录，附加 `--check` 可只核对。旧动作保留在现有资源槽，随对应新稿完成逐套替换。幼体立绘工具只处理静帧。
