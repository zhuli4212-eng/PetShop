# 原色兔独立四相跳跃

六种花色分别为栗野、灰野、黑白花斑、橘白花斑、纯黑、雪白。本批覆盖成年 11 个身份和幼年 12 个身份。成年栗野公兔沿用此前确认的独立四帧稿。

每次 ImageGen 生成两至三行母稿，每行指定一只原色兔的年龄、花色和性别，依次画出蓄力、蹬地、腾空收脚、前爪着地。输入图只含这些个体对应年龄的正式静帧。成年与幼年分别生成。文件中的行序见[批次与完整标识](批次.json)，每张母稿对应的生成请求见[提示词](提示词.json)，原始输入图保存在[参考](参考)，生成输出保存在[母稿](母稿)。

## 导出

从项目根目录运行以下命令。依赖 Pillow、NumPy 和 OpenCV。

```powershell
python -B "制作/动物图集源稿/独立逐帧行走/兔全量/原色兔/export_frames.py"
```

[导出脚本](export_frames.py)按连通轮廓及其行列切出每格，用对应个体的立绘可见面积确定一套动作的统一等比缩放，保留蹬地时身躯拉长和腾空时收短的差异。每格只清透明杂点、等比缩放、平移注册。着地线是 96×96 格的 y=89，第三格成年离地 8 像素，幼年离地 5 像素。落地帧和蓄力帧的接缝保留前爪接触。最终行走条为横排 384×96。
