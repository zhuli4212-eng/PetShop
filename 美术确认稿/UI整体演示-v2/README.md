# 宠物店 · 美术与 UI 整体演示

打开 `index.html` 即可查看，自包含离线文件，无需服务器。

## 本轮范围
只制作美术和 UI。19 个可切换页面：店铺、动物房间、繁育台、繁育完成、动物档案、普通订单、自由市场、研究所、特殊来客、装饰、比赛、比赛结果、奖杯收集册、研究技能树、房间解锁、养成道具、账号、模拟支付、额外取消次数。

继承原预览的暖木像素场景、深绿标题栏、米色卡片、方角控件。没有覆盖旧预览、没有部署或推送，没有写入玩法/服务器/支付代码。

页面切换、房间切换、提示弹窗仅用于审阅；金额、计时、动物、名次是静态样例。没有存档、经济结算、繁育生成、支付调用或资产发放。技能树节点展示方向，未将未定效果和价格冒充定稿。原有草图入口可从顶部模块选择器查看。

## 高清与适配
设计逻辑基准 390×844，19 张截图为设备缩放 3 倍的 1170×2532 PNG。文字为浏览器原生字体；像素资源采用 pixelated 渲染，不将整屏低清图放大。320×667、360×800、375×812、390×844、414×896、430×932 均检查了全部页面，未发现图片载入失败、JavaScript 错误或文档横向溢出。内部纵向滚动正常，联系图只显示首屏。

已检查订单取消演示弹窗的打开、关闭与返回店铺。不是完整功能测试；没有测试真机、微信胶囊、iOS动态地址栏/刘海或实际触控。CSS 预留 env(safe-area-inset-*) 不等于真机验收。
