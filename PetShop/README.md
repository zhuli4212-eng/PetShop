# 宠物店

Cocos Creator 3.8.8 的 2D 项目。主场景在 `assets/scenes/ShopMain.scene`，本地店铺服务在 `server/main.mjs`。

首页的门窗、家具和招牌对照[已确认的分层像素预览](../制作/首页场景拆分/首页拼图预览.html)。首页侧门和页脚「进入兔房」都打开动物房间。上方门牌切换物种，房景下方是本房的完整名册，可用「状态」和「成长状态」两个下拉框组合筛选。操作提示出现在游戏顶部的标题栏下方。

## 开始游戏

电脑双击 `启动宠物店.cmd`，手机浏览器打开[正式版](https://www.petshop-trial.fun/petshop/)，或[备用入口](https://play.zhu-li-4212.xyz/petshop/)。输入同一店主账号与密码即可继续经营同一家店。游戏与账号存档现由阿里云香港服务器承接，旧 ChatGPT 私有店铺入口不再作为当前游戏入口。换电脑开发见[迁移说明](../新电脑继续开发.md)。

需要继续旧的本机进度或离线测试时，在 Windows 上双击 `start-offline.cmd`。这个入口启动或复用 `127.0.0.1:17888` 的本机服务，独立保存进度。点场景物件进入功能，功能内点返回回店铺。档案、核价等操作窗点返回回到发起功能。报价中的「修改选择」可以继续编辑原先勾选的动物。[完整返回规则](../设计定稿/界面层级与返回逻辑-v1.0.md)

## 异地多人试玩

以下是旧版本机账号名免密测试服，和当前香港正式服数据独立。邀请正式玩家请发送上方试玩网址，使用账号名与密码登录；无需启动下面的本机测试服。

每位玩家单独开店。新玩家点「注册」，输入账号名即可开店。以后每次打开或刷新游戏都会回到登录页。同一浏览器再次打开同一试玩地址时会自动填入上次成功登录的账号名，点「登录店铺」即可续玩，也可以改填另一个已注册的账号。换设备时手动输入原账号名即可。知道账号名的人都可以进入这家店。游戏里的「账号 → 切换多人账号」可以退出。

1. 开服电脑需要 Node.js 24 和 Cloudflare 的 `cloudflared`。这台电脑已装好两者。新电脑可从 [Cloudflare 官方下载页](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/) 安装并把 `cloudflared` 加入 PATH，也可以设置 `CLOUDFLARED` 指向可执行文件。
2. 双击 `启动多人试玩服.cmd`，等窗口出现「异地试玩地址」。将这个完整的 HTTPS 网址发给玩家，电脑浏览器也用同一个网址登录。当前地址同时写入 `local/multiplayer/试玩地址.url`。保持开服电脑联网、唤醒和运行。
3. 结束时在窗口按 Ctrl+C，或双击 `停止多人试玩服.cmd`。再次开服时将新网址发给玩家，账号和进度继续保存在这台电脑。临时入口适用于试玩，重开会更换地址。[Cloudflare 临时隧道说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

多人数据保存在 `local/multiplayer/multiplayer.sqlite`。备份时先停服，再复制整个 `local/multiplayer` 目录；换机时还原此目录。个人云端店铺和 `local/local_sim` 的离线档各有独立入口。

需要固定域名时，将 HTTPS 反向代理或固定隧道指向 `http://127.0.0.1:17889`，给服务设置 `PUBLIC_ORIGIN=https://你的实际域名`，再运行 `node server/multiplayer.mjs`。单机开发可不设 `PUBLIC_ORIGIN`，直接运行同一命令后打开 `http://127.0.0.1:17889/`。通过 `MULTIPLAYER_PORT` 和 `MULTIPLAYER_DATA_DIR` 可单独指定端口及数据目录。

## 在编辑器里开发

在工程目录运行 `.\启动宠物店.cmd --editor`，按同样的顺序启动服务和编辑器。按 Cocos 的预览按钮即可测试改动；Canvas 上的 ShopMain 组件可以指定其他店铺服务器地址。

本地游戏使用 Web Mobile 构建。首次检出工程或改动客户端后，在工程根目录用 PowerShell 构建，然后双击 `start-offline.cmd`。

```powershell
& 'D:\app\CocosCreator\3.8.8\CocosCreator.exe' --project (Get-Location).Path --build ('configPath=' + (Resolve-Path 'tools/build-web-mobile.json').Path)
```

## 开店与经营

首页「任务」显示一组开店行为，可点条目进入对应界面，操作成功后逐条标记完成。已有档在首页底部显示完成数量，点击可前往下一项。培育中心和普通订单通常在店铺 2 级开放。完成引导中的开店任务或已有档原来的开店任务后，可手动领取一次 40 金币和 2 份臻选兔兔营养餐。点击门口签到礼盒领取后，弹窗显示两只幼兔的姓名、性别、品种、花色和成长阶段。

用 `start-offline.cmd` 新建的本机店铺带 680 金币进入 0–17 步开店引导。玩家免费开放兔房后获得一公一母原色幼兔。首次免费投喂使这两只幼兔立即成年，首窝繁育等待 5 秒。引导按店铺保存，重新进入时可点首页左下角的引导继续。已有经营档沿用原本的开店和任务记录。

本机验收可以用额外端口和空存档目录，启动后首页会从第 0 步开始。

```powershell
$env:PETSHOP_PORT='17920'
$env:PETSHOP_SAVE_DIR=Join-Path (Get-Location) ('local/guide-review-'+[guid]::NewGuid().ToString('N'))
.\start-offline.cmd
```

开店引导使用暗遮罩与文字提示，每次仅开放高亮控件。交接信需拆开阅读，拆信和各步骤进度都随店铺保存。首窝固定 4 只原色幼兔，公母各两只。出售一只首窝亲本后，未售亲本在成交时寿终，第 10 步可直接查看档案并去培育中心。首单按首窝第一只原色兔出生时的估值结算。

离线期间繁育和成长照常推进。引导留住后续操作需要的亲本、首单兔和已购种源，完成相应操作或结束引导后解除保护。

点门口礼物可领当天的一公一母两只基础幼兔，领取后礼物消失。点兔房侧门查看名册，或从「繁育」选种。兔、猫、狗的普通繁育分别等待 2、7、10 分钟。关掉游戏仍按服务器时间成长，繁育后亲本保留在房间。

本地数值基线中，猫房套餐基准价为 6,000 金币，狗房为 60,000 金币，均含一公一母幼体。房间按现行店铺折扣核价，已有入住回执保留成交时的价格。

普通订单、自由市场、特殊来客和动物回收均可勾选多只，核对逐只报价和合计后成交。特殊来客在订单内查看，有新来客时首页会弹出提醒。培育中心的「种源」「营养餐」「服务单」混排已开放房间的商品，场景右下角可进入「研究」和「动物回收」。点窗户可购置、摆出或收起四种装饰。右上柜上层进入赛事，下层查看荣誉。比赛仍按赛历结算，起点为北京时间 2026 年 11 月 9 日 20:00。

## 动物小屋投喂

兔房、猫房和狗房各有独立食碗和营养餐库存。点食碗选餐，每份只作用于本房，优质、精选、臻选分别为 1.5、1.8、2 倍成长速度，目前都按 30 分钟测试。生效期间食碗显示食物、倍率和剩余时间，到期后可以再次投喂。

营养餐只提前成年前的成长时点。离线继续计时，有效期内出生的幼体共享剩余时间，繁育等待、老年和死亡时点不变。培育中心的营养餐货架支持为已开放的房间按份购买，确认后扣金币并存入本房库存。优质、精选、臻选的本地测试价分别为兔房 8／9／10、猫房 32／36／40、狗房 80／90／100 金币。

## 声音

首次点击游戏按钮后播放原创循环背景音乐。按钮操作、投喂、首对兔成年、界面内等待的一窝出生、金币入账和领奖有各自的短音效。进入「账号 → 声音设置」可分别控制背景音乐与游戏音效。开关由当前浏览器记住，游戏切到后台时暂停音乐。

原始音频在 `assets/resources/audio`。如需重新制作，可在工程目录运行 `python tools/compose-shop-audio.py`，生成 MP3 需要 FFmpeg。

## 存档与联调

服务器将本机经营档保存在 `local/local_sim/shop.json`，滚动备份在同目录的 `backups`。账户身份、动物、金币、经营事件和成功操作回执随档保存。营养餐的余时、库存及已提前的成长时点一并保存。重新打开游戏会读取同一个档；设备时间回拨时按最后保存的经营时间继续。账号入口可以查看店主编号和经营账簿。模拟支付只在客户端演示，不扣费、不到账。

服务端可运行 `node --test server/*.test.mjs` 测试。接口包括首页、页面读取、经营操作、原请求回执和前后台心跳。开发测试可给独立服务设置 `PETSHOP_PORT` 与 `PETSHOP_SAVE_DIR`，分别隔离端口和存档。

## 本机赛事维护

运行游戏后，在同一 Windows 用户的 `PetShop` 工程目录用 PowerShell 查看本店正在举办的期号、报名状态和公布时间。

```powershell
node tools/maintain-show.mjs list
```

核实赛表等技术故障后，用查询到的期号作废整期。下面的期号是格式示例。

```powershell
node tools/maintain-show.mjs void private-7 "本期赛表配置错误"
```

本期须已开放且尚未公布结果。尚未报名的赛期也能作废，之后停止受理报名。已报名的私人赛退回原实付金币，公开赛原报名费为零。原因、原额退款和报名记录由运行中的店铺服务一次写入；重复执行显示原处理结果。已公布的奖项保留，作废赛期没有奖杯、奖金或补报名机会。

维护命令连接现有服务，默认使用本机 17888 端口。自定义端口的联调实例需给命令设置相同的 `PETSHOP_PORT`。服务每次启动在当前用户目录的 `.petshop/maintenance` 下轮换本进程的本地凭据。请勿共享该目录。更新前已经运行的旧服务需要正常重启一次以加载新代码，之后可在游戏运行期间直接维护。
